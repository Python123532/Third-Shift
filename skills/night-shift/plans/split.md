# TASK split (ID)

Replace one task with 2 to 5 subtasks. Each gets the parent's ID plus a letter (T-006a), its own Spec, Milestones, and Effort (S or M), and the parent's Tag, Priority, Runs, and Due. The parent stays in Tasks (SKILL.md, Task rule 7).

1. Letter the subtasks in the order they should be done.
2. Where one needs another's output (meeting plans need the timeline), propose a Depends On.
3. Show the subtasks, their order, and the dependencies together, and ask the user to confirm or change them before saving.
4. Save confirmed dependencies in Depends On (add the column if needed).
