# Starter templates

Offer these when the user asks for a template, or when their request clearly matches one. Fill in the parts in () with them, then continue plans/create.md from step 4. If the Tag has no Standards row, offer the template's suggested Standard as one of the options.

## Weekly research brief
- Spec: What: a one-page brief on what's new in (topic) since the last brief, at most (5) items, each with why it matters. Output: Google Doc '(topic) brief (date)' in the Task Manager folder. For: (who), plain and short.
- Milestones: 1) find and vet new sources 2) write the brief
- Effort S. Repeat weekly.
- Suggested Standard: every item links a primary source opened in this run; no item older than the last brief.

## Study guide
- Spec: What: a study guide for (course, unit or chapter): key terms with definitions, the main ideas, and (10) practice questions with answers at the end. Output: Google Doc '(unit) study guide' in the Task Manager folder. For: (me), studying for (test, date).
- Milestones: 1) list terms and main ideas from (textbook or class source) 2) write definitions and explanations 3) write practice questions and answers
- Effort M.
- Suggested Standard: match the class's own terms and sources; flag anything the source doesn't cover instead of guessing.

## Document cleanup
- Spec: What: tighten (doc link): fix errors, cut repetition, make it consistent, without changing its meaning or decisions. Output: edits in the same doc, with a short change list at the top. For: (audience).
- Milestones: 1) read it and list problems 2) make the edits and write the change list
- Effort S (M if the doc is long).
- Suggested Standard: never change a fact, number, or decision; list anything that looks wrong as a question instead.
